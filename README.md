# HADA HUB — Mentor Foundation (V1)

Giải nén rồi kéo TẤT CẢ file vào repo GitHub (giữ nguyên tên).

## File
- index.html   trang web, một file, đã gắn SEO và favicon
- ss3.mp3       giọng đọc buổi SS3 (bản thu của Khương, đã ghép)
- favicon.svg   logo chữ A, icon trên tab trình duyệt

## Bật link test
1. Tạo repo mới, Add file, Upload files, kéo cả ba file vào.
2. Settings, Pages, Branch main, thư mục / (root), Save.
3. Đợi khoảng một phút, có link https://<tên>.github.io/<repo>.

Các buổi sau khi có bản thu sẽ thêm ss4.mp3 ... ss8.mp3 vào cùng thư mục.
